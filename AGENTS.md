## Cursor Cloud specific instructions

Solar ERP is a single Next.js 16 App Router app (source under `src/`), not a monorepo. Standard commands live in `package.json` (`dev`, `build`, `lint`, `start`); the Cloud environment installs with `npm ci` and runs `npm run dev` in the `dev` terminal.

Non-obvious notes:

- The dev server is `next dev` (Turbopack) on `http://localhost:3000`. `npm run lint` is bare `eslint` (config in `eslint.config.mjs`); `npm run build` runs type-checking.
- Auth is temporary hardcoded cookie auth (no DB yet). Log in at `/login` with `admin@baoduy.com` / `admin123` (defined in `src/lib/auth.ts`); success sets the `solar_auth` cookie. Unauthenticated requests to `/` and `/dashboard/*` are redirected to `/login`.
- The auth guard is Next 16's middleware, which lives in `src/proxy.ts` (this Next version renames `middleware` → `proxy`), not `middleware.ts`.
- All dashboard data is mock data from `src/lib/mock-data.ts`; there is no backend/API service to run besides the Next app itself.
